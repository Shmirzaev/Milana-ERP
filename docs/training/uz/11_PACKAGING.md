# Qadoqlash bo'yicha o'quv qo'llanma

Versiya: 1.0
Sana: 2026-07-02
Bo'lim kodi: PKG
Standart rol: Qadoqlash

## Maqsad

Qadoqlash qadoqlangan tovarlarni qayd qiladi, paket yorliqlarini yaratadi, paket tarkibini nazorat qiladi va tayyor mahsulotni saqlash uchun paketlarni tayyorlaydi.

## Bosh sahifalar

- Qadoqlash qavati
- Qadoqlash bo'yicha ish tartibi
- Paketlar
- Paketni skanerlash
- Jarayonni kuzatish
- Kuzatish imkoniyati

## Asosiy ruxsatlar

- `packaging.records`
- `packaging.packages`
- `payroll.scan`
- `traceability.view`

## Kundalik ish jarayoni

1. Qadoqlash qavatini oching.
2. Tikuvchilikdan tayyor ishni ko'rib chiqing.
3. Qadoqlash bo'yicha ish buyrug'ini oching.
4. Agar kerak bo'lsa, to'plamni tanlang.
5. Kirish, qadoqlangan miqdor, shikastlangan miqdor, qadoqlash materiallari va eslatmalarni yozib oling.
6. Paketlarni yarating.
7. Paket tarkibini, hajmini, vaznini va nusxalarini ko'rib chiqing.
8. Paket yorliqlarini chop eting.
9. Jismoniy paketlarga teglar biriktiring.
10. Skanerlash uchun paketlarni tayyor mahsulot omboriga topshiring.

## Qadoqlash chiqishini yozib olish

Maydonlar:

1. Ishlab chiqarish partiyasi, agar partiyali bo'lsa.
2. Kirish miqdori.
3. Qadoqlangan/chiqarish miqdori.
4. Shikastlangan miqdor.
5. Qadoqlash materiallari ishlatilgan.
6. Eslatmalar.

Agar bu jamoaning protsedurasi bo'lsa, paket yorliqlarini yaratishdan oldin qadoqlash yozuvini saqlang.

## Paketlarni yaratish

Paket yaratuvchisi quyidagilarni qo'llab-quvvatlaydi:

1. Rang.
2. Paket hajmi.
3. Standart vazn.
4. Paket nusxalari.
5. Har bir paket ichidagi o'lcham miqdori.
6. Paketning individual og'irliklari.
7. Faqat to'liq paketli variant.
8. To'plamli buyurtmalar uchun yoqilgan bo'lsa, to'plamlar bo'ylab birlashtiring.

Agar o'zgartirilmasa, standart paket hajmi 60 dona. Haddan tashqari sig'imli yoki aralash modeldagi istisnolar tegishli tasdiqlashni / bekor qilishni talab qiladi.

## To'liq va qisman paketlar

Oldindan ko'rish quyidagilarni ko'rsatadi:

1. To'liq paketlar.
2. To'liq bo'lmagan paketlar.
3. Paket hajmi.
4. Faqat toʻliq paket yoqilgan boʻlsa, kutilayotgan qoldiqlar.

Agar faqat to'liq paket yoqilgan bo'lsa, qisman paketlar yaratilmaydi. Qolganlarni nazoratchiga xabar qiling.

## Paketli qadoqlash

To'liq buyurtmalar uchun:

1. Qadoqlash chiqishini saqlashdan oldin to'g'ri partiyani tanlang.
2. To‘plam jarayonini ko‘rib chiqing.
3. Birlashma to‘plamlardan faqat nazoratchi bir nechta partiya qoldiqlaridan bitta to‘liq paketni qadoqlashni ma’qullaganida foydalaning.
4. Yorliqlarni chop etishdan oldin paketlarning taqsimlanishini tasdiqlang.

## Yorliq qoidalari

1. Paket yaratilgandan so'ng darhol teglarni chop eting.
2. Yorliqni to'g'ri paketga yopishtiring.
3. Yorliq shikastlangan bo'lsa, faqat mavjud paket yozuvidan qayta chop eting.
4. Yo'qolgan teglarni almashtirish uchun ikki nusxadagi paketlarni yaratmang.

## Tayyor mahsulotni saqlash joyiga topshirish

1. Paketda yorliq bo'lishi kerak.
2. Paket holati qadoqlangan bo'lishi kerak.
3. Jismoniy paketlar soni ERP paketlar soniga mos kelishi kerak.
4. Tayyor mahsulotni saqlash paketni katakka/javonga skanerlaydi.
