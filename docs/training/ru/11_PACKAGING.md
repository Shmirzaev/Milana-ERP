# Учебное пособие по упаковке

Версия: 1.0
Дата: 2 июля 2026 г.
Код отдела: PKG
Роль по умолчанию: Упаковка

## Цель

Упаковка фиксирует упакованные товары, создает этикетки для упаковок, контролирует содержимое упаковок и подготавливает упаковки к хранению готовой продукции.

## Главные страницы

- Упаковочный пол
- Заказ на упаковку
- Пакеты
- Сканировать пакет
- Отслеживание процессов
- Прослеживаемость

## Ключевые разрешения

- `packaging.records`
- `packaging.packages`
- `payroll.scan`
- `traceability.view`

## Ежедневный рабочий процесс

1. Открытый упаковочный этаж.
2. Обзор готовой работы из Шитья.
3. Откройте заказ на упаковку.
4. При необходимости выберите партию.
5. Запишите входные данные, упакованное количество, поврежденное количество, упаковочный материал и примечания.
6. Создавайте пакеты.
7. Просмотрите содержимое упаковки, ее вместимость, вес и количество копий.
8. Распечатайте этикетки для пакетов.
9. Прикрепите этикетки к физическим упаковкам.
10. Передайте упаковки в хранилище готовой продукции для сканирования.

## Запись вывода упаковки

Поля:

1. Производственная партия, если она была серийной.
2. Входное количество.
3. Упакованное/выходное количество.
4. Поврежденное количество.
5. Используемый упаковочный материал.
6. Примечания.

Сохраните запись об упаковке перед созданием этикеток, если это процедура группы.

## Создание пакетов

Создатель пакета поддерживает:

1. Цвет.
2. Емкость упаковки.
3. Вес по умолчанию.
4. Копии пакетов.
5. Размер количества внутри каждой упаковки.
6. Вес индивидуальной упаковки.
7. Вариант только с полным пакетом.
8. Объединение партий, если эта функция включена для пакетных заказов.

Емкость упаковки по умолчанию составляет 60 штук, если не изменена. Исключения, связанные с избыточной мощностью или смешанной моделью, требуют соответствующего утверждения/переопределения.

## Полные и частичные пакеты

Предварительный просмотр показывает:

1. Полные пакеты.
2. Неполные пакеты.
3. Емкость упаковки.
4. Ожидающие остатки, если включен только полный пакет.

Если включен параметр «Только полный пакет», частичные пакеты не создаются. Сообщите об остатках руководителю.

## Пакетная упаковка

Для пакетных заказов:

1. Выберите правильную партию перед сохранением результатов упаковки.
2. Просмотрите ход выполнения партии.
3. Используйте объединение партий только в том случае, если руководитель утверждает упаковку одной полной упаковки из остатков нескольких партий.
4. Прежде чем печатать этикетки, подтвердите распределение упаковок.

## Правила этикетки

1. Печатайте этикетки сразу после создания упаковки.
2. Прикрепите этикетку к нужной упаковке.
3. Повторная печать только из существующей записи об упаковке, если этикетка повреждена.
4. Не создавайте дубликаты пакетов для замены отсутствующих этикеток.

## Передача на склад готовой продукции

1. На упаковке должна быть этикетка.
2. Статус посылки должен быть упакован.
3. Количество физических пакетов должно соответствовать количеству пакетов ERP.
4. Ready Product Storage сканирует упаковку в ячейку/полку.

## Распространенные проблемы

| Проблема | Вероятная причина | Действие |
| --- | --- | --- |
| Невозможно создать пакет | Содержимое упаковки недействительно, нет упаковываемого количества или проблема с емкостью | Просмотрите предварительный просмотр и упакуйте элементы. |
| Слишком большое количество пакетов | Копии или емкость установлена неправильно. | Исправьте ошибки перед созданием ярлыков. |
| Готовое хранилище не может получить | Посылка не упакована или неправильный статус | Проверьте детали пакета и историю сканирования. |
| Поврежденный товар не отражен | Количество поврежденных грузов не зафиксировано | Сохраните запись об упаковке с указанием поврежденного количества. |
