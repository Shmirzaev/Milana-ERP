# Учебное пособие для Департамента отходов

Версия: 1.0
Дата: 2 июля 2026 г.
Код отдела: WST
Роль по умолчанию: Отходы

## Цель

Департамент по отходам осуществляет учет, получение, продажу или утилизацию отходов производства. Записи об отходах помогают руководству понять потери, возместить стоимость продаваемых отходов и одобрить утилизацию непродаваемых отходов.

## Главные страницы

- Панель управления отходами
- Список материалов/предметов для выбора отходов
- Список отделов для выбора исходного отдела
- Отчет о финансовых растратах, прочитанный отделом финансов/менеджмента

## Ключевые разрешения

- `waste.receive`
- `waste.sell`
- `waste.disposal`

## Ежедневный рабочий процесс

1. Откройте панель управления отходами.
2. Проверьте количество продаваемых и непродаваемых отходов.
3. Записывайте отходы, если ваша команда создает записи об отходах напрямую.
4. Получайте отходы физически из источника.
5. Продавайте пригодные для продажи отходы, если это одобрено местной процедурой.
6. Запросите утилизацию неликвидных отходов.
7. Маркировка утилизируется только после утверждения и физической утилизации.

## Учет отходов

Поля:

1. Пункт.
2. Исходный отдел.
3. Тип отходов.
4. Количество.
5. Единица.
6. Продаваемый флажок.
7. Причина, если этого требует процесс.

Используйте физический счетчик/вес. Не проводите оценку, если руководитель явно не разрешил это.

## Прием отходов

1. Сопоставьте запись об отходах с физическими отходами.
2. Подтвердите отдел источника и тип отходов.
3. Подтвердите количество и единицу измерения.
4. Выберите Получить.
5. Храните физические отходы в зоне для мусора.

## Продажа продаваемых отходов

1. Подтвердите, что статус отходов получен отделом отходов.
2. Подтвердите, что отходы помечены как пригодные для продажи.
3. Подтвердите покупателя и цену в соответствии с местным процессом утверждения.
4. Выберите «Продать».
5. Сохраняйте документы о продаже для финансов.

## Утилизация нетоварных отходов

1. Подтвердите, что статус отходов получен отделом отходов.
2. Подтвердите, что отходы не подлежат продаже.
3. Выберите «Запросить удаление».
4. Введите причину.
5. Дождитесь одобрения руководства.
6. После утверждения и физической утилизации маркировка удаляется.

Нетоварные отходы не должны выбрасываться до получения разрешения.

## Статус Значение

| Статус | Значение |
| --- | --- |
| записано | Отходы были зарегистрированы, но еще не получены Департаментом по отходам. |
| получено_by_waste_department | Департамент по отходам принял физические отходы. |
| продан | Товарный мусор был продан. |
| pending_disposal_approval | Утилизация запрошена и ожидает руководства. |
| удаление_одобрено | Утилизация одобрена руководством. |
| распоряжаться | Отходы были физически удалены, а ERP был обновлен. |

## Распространенные проблемы

| Проблема | Вероятная причина | Действие |
| --- | --- | --- |
| Количество отходов не соответствует физическим отходам | Ошибка ввода исходного отдела | Попросите руководителя источника подтвердить перед получением. |
| Не могу продать | Отходы, не полученные или не подлежащие продаже | Получите первый или правильный флаг продажи через супервизора/администратора. |
| Невозможно утилизировать | Нет одобрения руководства | Запросите одобрение и ждите. |
| Несоответствие финансового отчета | Продажа/выбытие записаны неправильно. | Проверьте статус отходов и документы о продаже. |
