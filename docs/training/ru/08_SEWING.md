# Учебное пособие по шитью

Версия: 1.0
Дата: 2 июля 2026 г.
Код отдела: SEW
Роль по умолчанию: Швейный отдел

## Цель

Швейный отдел получает пакеты, записывает вышитые результаты, количество неудачных/переработанных/отбракованных изделий и отслеживает работу по вышивальным линиям или заданиям.

## Главные страницы

- Швейный пол
- Заказ на швейные работы
- Швейные процессы
- Пакет сканирования
- Сканирование заработной платы
- Отслеживание процессов
- Прослеживаемость

## Ключевые разрешения

- `sewing.records`
- `sewing.bundles`
- `payroll.scan`
- `traceability.view`

## Ежедневный рабочий процесс

1. Откройте швейный цех или назначенный заводской цех.
2. Просмотрите работу, назначенную вашей линии/заводу.
3. Получайте пакеты с помощью Scan Bundle.
4. Откройте заказ на шитье.
5. При необходимости выберите производственную партию.
6. Выберите строку/назначение.
7. Запишите ввод, вышитый результат, сбой, переработку, отказ, причину дефекта и примечания.
8. Сохранить запись.
9. При необходимости используйте сканирование заработной платы.
10. Убедитесь, что завершенная работа доступна для упаковки.

## Получение пакетов

1. Откройте пакет сканирования для шитья.
2. Сканируйте штрих-код комплекта.
3. Подтвердите модель, цвет, размер, количество, текущий отдел, следующий отдел и завод.
4. Если статус — `sent_to_sewing`, выберите «Получить на заводе».
5. Если комплект создан для прямого пошива и страница позволяет получить, получите его.

Не получайте комплекты не той фабрики или не той линии.

## Выбор линии и назначения

В наряде на швейные работы могут быть указаны:

1. Назначенные потоки шитья.
2. Разделить задания.
3. Оставшееся количество по заданию.
4. Порядок вышивания рабочего задания по умолчанию.
5. Все доступные потоки, если не существует конкретного назначения.

Выберите правильную строку перед сохранением вывода.

## Запись результатов шитья

Поля:

1. Производственная партия, если заказ пакетный.
2. Входное количество.
3. Сшитое/выходное количество.
4. Неудачное количество.
5. Количество доработок.
6. Отклоненное количество.
7. Имя линии или назначение.
8. Причина дефекта.
9. Примечания.

Система использует отшитую продукцию в качестве переданного количества для упаковки.

## Количественные правила

1. Ввод не должен превышать количество переданных выше по течению частей.
2. Вывод должен отражать физически сшитые детали.
3. Неудачные части следует считать отдельно.
4. Детали переделки не должны быть скрыты.
5. Отбракованные детали должны быть зарегистрированы с указанием причины дефекта.

## Сканирование заработной платы

В шитье обычно используются сканы сдельной заработной платы.

1. Откройте сканирование заработной платы.
2. Сначала отсканируйте бейдж сотрудника.
3. Процесс сканирования/работы QR занимает секунду.
4. Подтвердите модель, производство, партию, операцию, количество, скорость и общую сумму.
5. Сохраните скан или Сохранить все.
6. Не сканируйте один и тот же рабочий QR дважды для одной и той же оплачиваемой операции.

## Контрольный список в конце смены

1. Все физические результаты шитья сохраняются.
2. Вводятся неудавшиеся/переработанные/отбракованные количества.
3. Сканирование расчетов заработной платы сохраняется, а не только хранится в локальном сеансе.
4. Незавершенные пакеты физически отделены от завершенных пакетов.
5. Супервайзер знает о заблокированных пакетах или пакетах с риском для качества.

## Распространенные проблемы

| Проблема | Вероятная причина | Действие |
| --- | --- | --- |
| Не могу получить пакет | Предыдущий отдел его не отправил | Попросите вырезать/печать отправить. |
| Показана неправильная линия | Назначение не задано или выбран неправильный поток | Попросите менеджера по планированию/руководителя обновить назначение. |
| Ошибка количества | Швейный вход/выход превышает допустимое количество на входе | Проверьте количество пакетов/заказов на работу и предыдущие записи отдела. |
| Дубликат заработной платы | Тот же рабочий QR-код уже сохранен | Просмотрите историю сканирования и сохраненный статус. |
