# Милана ERP Учебная библиотека по отделам

Версия: 1.0
Дата: 2 июля 2026 г.
Аудитория: сотрудники подразделений, супервайзеры, тренеры, руководство, администраторы и суперадмины.

В этой папке учебные материалы ERP разделены по отделам, поэтому каждая команда может тренироваться на тех экранах и обязанностях, которые они фактически используют.

Начните с полного обзора процесса, затем откройте руководство для отдела сотрудника.
