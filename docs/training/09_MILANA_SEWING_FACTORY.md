# Milana Sewing Factory Training Manual

Version: 1.0
Date: 2026-07-02
Department code: MIL
Role used: Sewing

## Purpose

Milana Sewing Factory is a sewing execution department. It uses the Sewing role but receives only the bundles and work assigned to the Milana factory.

## Main Pages

- Milana Sewing
- Sewing Work Order
- Scan Bundle
- Payroll Scan
- Sewing Flows
- Process Tracking

## Daily Workflow

1. Open Milana Sewing.
2. Review incoming and assigned work.
3. Scan bundles addressed to Milana.
4. Confirm bundle sewing factory is Milana before receiving.
5. Record output on the Sewing Work Order.
6. Use the correct line/assignment.
7. Save payroll scans if piecework is tracked.
8. Send completed work toward Packaging according to supervisor process.

## Factory-Specific Rules

1. Do not receive Besttex bundles.
2. Do not change the factory destination on the shop floor.
3. If a bundle is routed to the wrong factory, stop and ask the supervisor or Planning.
4. Keep Milana and Besttex bundles physically separated.
5. Report missing or damaged bundle labels immediately.

## Sewing Record Rules

Use the same sewing output rules as the main Sewing department:

1. Select correct batch if batched.
2. Select correct line.
3. Enter input.
4. Enter sewn output.
5. Enter failed, rework, rejected, and defect reason.
6. Save.

## Payroll Scan

1. Scan the employee assigned to the operation.
2. Scan the correct work/process QR.
3. Confirm operation belongs to the correct batch/order.
4. Save payroll scans before clearing the session.

## Common Problems

| Problem | Likely cause | Action |
| --- | --- | --- |
| Bundle says Besttex | Cutting selected wrong factory or bundle belongs elsewhere | Do not receive; notify supervisor. |
| No receive action | Bundle not sent or wrong status | Ask previous department to scan/send. |
| Missing assignment | Planning has not assigned flow | Ask Planning/supervisor. |
