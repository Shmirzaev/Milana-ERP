# Besttex Textile Packaging Training Manual

Version: 1.0
Date: 2026-07-02
Department code: BPK
Role used: Packaging

## Purpose

Besttex Textile Packaging handles packaging work routed to the Besttex packaging department. It uses the Packaging role but should only package work assigned to Besttex Textile Packaging.

## Main Pages

- Besttex Packaging
- Packaging Work Order
- Packages
- Scan Package
- Process Tracking

## Daily Workflow

1. Open Besttex Packaging.
2. Review assigned work.
3. Confirm order, model, color, size, batch, and planned quantity.
4. Record packed and damaged output.
5. Create packages with correct sizes and capacity.
6. Print labels and attach them immediately.
7. Transfer packages to Ready Product Storage for receiving scan.

## Department-Specific Rules

1. Package only work assigned to Besttex Textile Packaging.
2. Keep Besttex package labels separate from main Packaging labels.
3. Do not change production batch or package contents to force a label.
4. Report mixed or over-capacity packages before creating labels.
5. Check package weight when required.

## Package Creation Checklist

1. Correct batch selected if batched.
2. Packed quantity has been recorded.
3. Color is correct.
4. Size distribution matches physical contents.
5. Capacity is correct.
6. Copies match physical package count.
7. Weight values are entered if used.
8. Labels are printed once packages are created.

## Common Problems

| Problem | Likely cause | Action |
| --- | --- | --- |
| Wrong department work appears | Permission gives wider packaging access | Package only assigned Besttex work and tell supervisor. |
| Label does not match contents | Package size rows wrong | Stop and ask supervisor before storage receives package. |
| Partial package remains | Full-package-only or insufficient quantity | Keep leftover documented and notify supervisor. |
