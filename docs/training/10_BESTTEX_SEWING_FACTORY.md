# Besttex Sewing Factory Training Manual

Version: 1.0
Date: 2026-07-02
Department code: BST
Role used: Sewing

## Purpose

Besttex Sewing Factory is a sewing execution department. It uses the Sewing role but receives bundles routed to Besttex.

## Main Pages

- Besttex Sewing
- Sewing Work Order
- Scan Bundle
- Payroll Scan

- Process Tracking

## Daily Workflow

1. Open Besttex Sewing.
2. Review incoming and assigned work.
3. Scan only bundles routed to Besttex.
4. Confirm model, color, size, quantity, batch, and order.
5. Record sewing output and defects.
6. Save payroll scans when applicable.
7. Keep completed work ready for the next packaging step.

## Factory-Specific Rules

1. Do not receive Milana bundles.
2. Do not continue if label destination and physical paperwork disagree.
3. Keep Besttex work physically separate by order and batch.
4. Use defect reasons for quality problems.
5. Tell Planning if capacity or deadline risk appears.

## Sewing Record Rules

1. Select production batch when required.
2. Select line/assignment.
3. Enter input quantity.
4. Enter sewn/output quantity.
5. Enter failed, rework, rejected quantities.
6. Add defect reason and notes.
7. Save record.

## Payroll Scan

1. Scan employee QR.
2. Scan work/process QR.
3. Confirm work belongs to Besttex work.
4. Save records.

## Common Problems

| Problem | Likely cause | Action |
| --- | --- | --- |
| Bundle is routed to Milana | Wrong physical bundle or wrong ERP route | Stop and notify supervisor. |
| Quantity mismatch | Previous stage count or sewing entry mismatch | Check bundle/work order history before saving. |
| No line available | Assignment missing or line full | Ask Planning/supervisor. |
