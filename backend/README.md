# Milana ERP API

FastAPI backend for Milana ERP.

This folder is intended to be deployed as a Hugging Face Docker Space. Configure
the runtime secrets listed in `docs/HUGGING_FACE_DEPLOY.md`, then point the
Vercel frontend at the Space URL with `NEXT_PUBLIC_API_URL` and `API_URL`.
